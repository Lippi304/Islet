## Idea

User again took inspiration from the app "Droppy" (referenced before this session — "wieder von
Droppy geklaut", i.e. "stolen from Droppy again"). Wants the expanded Calendar view made wider
and redesigned to look truly identical ("wirklich 1:1", "originalgetreu nachbauen") to macOS's
own native Calendar app — not just inspired by it, an exact visual reproduction.

Reference screenshot reviewed (2026-07-29, `image-cache/.../12.png`, from "Droppy"): a wide
two-column layout inside the expanded panel. Left column: a full month grid ("JULY" in red/orange
+ a "+" button top-left, prev/next chevrons top-right, M–S weekday header row, today's date
highlighted with a solid red circle, a second date highlighted with a red circle outline —
presumably the currently-selected/viewed date). Right column: a scrollable agenda list grouped by
day headers ("WEDNESDAY, 15 JUL (WK. 29)" etc.), each event shown as a colored vertical bar +
event title (colored to match, e.g. blue/green) + time below. Below the whole panel: the
persistent bottom pill (home / inbox-with-badge-count / apps-grid icons as one capsule, plus a
separate circular calendar-with-badge icon) — same bottom-pill convention Droppy uses across all
its reference screenshots in this idea set, worth checking if Islet already has an equivalent
persistent dock/pill or if that's out of scope for this specific redesign.

This is explicitly a redesign of the EXISTING calendar/full-view feature (Phase 28
`28-calendar-full-view`, already shipped) — not a new feature from scratch.
