## Idea

When a file is dropped into the File Tray, the existing view shows 3 actions today. Add a 4th
button — "Convert" — that appears specifically when the dropped item(s) are images (e.g. JPG).
Tapping it should offer the same image-format conversion choices macOS's own Finder
right-click → "Convert Image" menu offers (e.g. JPG ↔ PNG, and whatever other formats that
system menu exposes), so the File Tray becomes a quick drag-and-drop version of that same
conversion tool.
