**`scheduleActivityDismiss()`'s own work-item body to mirror exactly for the clear-all function**
(`Islet/Notch/NotchWindowController.swift` lines 2798-2809):

```swift
let work = DispatchWorkItem { [weak self] in
    guard let self else { return }

        self.syncActivityModels()
        self.renderPresentation()

```
`transientQueue.removeAll(where:)` (`Islet/Notch/IslandResolver.swift` lines 493-499) is the
existing method to clear the ENTIRE queue (head + pending) in one call: `mutating func
removeAll(where predicate: (ActiveTransient) -> Bool)`. `syncActivityModels()`,
`renderPresentation()`, `updateVisibility()`, `springResponse`, `springDamping`, `dismissWorkItem`,
and `transientQueue` are all existing `private` members of the SAME `NotchWindowController` class

calls `transientQueue.removeAll(where: { _ in true })` instead of `transientQueue.advance()` (it
clears everything, not just the head), and it does NOT re-arm `scheduleActivityDismiss()` or call
`deviceCoordinator.activityPromoted()` afterward (there is nothing left to promote — the queue is
empty by construction).
