```swift
static var isAccessibilityTrusted: Bool { AXIsProcessTrusted() }
func start() {
    guard monitorToken == nil else { return }
    guard Self.isAccessibilityTrusted else { armHealthCheck(); return }
    install()
}
private func armHealthCheck() {
    guard healthCheckTimer == nil else { return }
    healthCheckTimer = Timer.scheduledTimer(withTimeInterval: 5, repeats: true) { [weak self] _ in
        DispatchQueue.main.async { [weak self] in
            guard let self, self.monitorToken == nil, Self.isAccessibilityTrusted else { return }
            self.install()
        }
    }
}
nonisolated func stop() { /* invalidate timer, remove monitor token */ }
deinit { /* empty by design — owner calls stop() */ }
```

## Trust Boundaries

| Boundary | Description |
|----------|--------------|

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-66-07 | Elevation of Privilege / Access Control (V4) | `MenuBarOverflowController.start()`/`evaluate()` | mitigate | Every code path that touches `MenuBarOverflowBridging` is reached only through `install()`, itself reachable only after `isAccessibilityTrusted` is confirmed — an untrusted state is a silent no-op (health-check keeps retrying), never a crash or a dialog, mirroring `DropInterceptTap`'s documented "a nil tap is a silent no-op" precedent |
| T-66-08 | Repudiation (a move silently "succeeding" with no real effect) | `evaluate()`'s reapplication path | mitigate | `moveMenuBarItem` returns `Bool`; a `false` result is logged but never causes an infinite retry loop within the same `evaluate()` pass — the next poll-timer/notification tick naturally retries |
| T-66-09 | Tampering (accidental cross-feature coupling with Islet's own status items) | `windowsOfOtherApps()` | mitigate | Explicit `Bundle.main.bundleIdentifier` exclusion filter, unit-verified via grep in Task 1's acceptance criteria |
