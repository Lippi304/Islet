        }
    }

    - `hiddenBundleIdentifiers(defaults:)` returns an empty `Set<String>` when nothing has ever been persisted (fresh install / fresh UserDefaults suite).
    - `setHiddenBundleIdentifiers(_:defaults:)` followed by `hiddenBundleIdentifiers(defaults:)` on the SAME `UserDefaults` instance round-trips exactly the same set (order-independent — compare as `Set`, not `Array`).
    - Calling `setHiddenBundleIdentifiers` a second time with a DIFFERENT set fully REPLACES the prior set (not a union) — a bundle ID present in the first call but absent from the second call is no longer present after the second call. This is the exact mechanic that lets a user un-hide an icon by dragging it back out (Task 2 relies on replace-not-union semantics).
    - An empty `Set<String>` persists and reads back as empty (not `nil`, not crashing).
  </behavior>
