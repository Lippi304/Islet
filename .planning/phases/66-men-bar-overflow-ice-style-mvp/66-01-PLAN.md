<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| App process → macOS Window Server (via private CGS*/`@_silgen_name` symbols) | Out-of-process introspection of other apps' windows — private, undocumented, no stability contract |
| App process → other apps' `NSStatusItem` windows (via synthetic `CGEvent` drag) | The only write path; simulates a real user drag, gated entirely behind Accessibility trust |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-66-01 | Tampering | `MenuBarOverflowBridging.moveMenuBarItem` | mitigate | Bounded 5-attempt retry (Ice's `wakeUpItem()` precedent), fail closed on exhaustion (return `false`, leave item wherever it currently sits — never loop indefinitely or force a partial move) |
| T-66-02 | Elevation of Privilege (inherent to the Accessibility grant itself, not introduced by this file) | Synthetic `CGEvent` generation | accept, scoped | Any process with Accessibility trust can synthesize input events system-wide; this file scopes usage strictly to the one documented move sequence and never exposes a generalized "send arbitrary event" helper |
| T-66-03 | Information Disclosure | Window-list read (bundle IDs, window frames of other processes) | accept | Menu-bar icon presence/position is already public, user-visible information — no sensitive data crosses this boundary |
| T-66-04 | Denial of Service (local, this app crashing on a malformed/nil CGS result) | `MenuBarOverflowBridging` symbol calls | mitigate | Every CGS return value is checked before use; no force-unwraps; a failed read returns an empty/nil result, never a crash |
</threat_model>
