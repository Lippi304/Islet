# Phase 62 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — native macOS SwiftUI app (no `components.json`, no `package.json`, no web component registry) |
| Preset | not applicable |
| Component library | none — all controls are hand-rolled SwiftUI views in `Islet/Notch/NotchPillView.swift` (`navCircleButton`, `chipButton`, `wingsShape`, `blobShape`) |
| Icon library | SF Symbols (`Image(systemName:)`), `.symbolRenderingMode(.hierarchical)` for secondary glyphs, `.monochrome` for icons that must read as fully opaque/prominent (Phase 61 precedent) |
| Font | System font, `design: .rounded` variant on every label/body/heading text; countdown digits use `.monospacedDigit()` to prevent width jitter as the number changes |

This phase adds **zero new visual primitives**. Every control below reuses an existing, on-device-proven pattern from `NotchPillView.swift` — do not invent a new button/chip/sheet style.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps inside wing rows (matches `iconLabelGap` in `updateWings`) |
| sm | 8px | Compact control padding (`chipButton` horizontal/vertical) |
| md | 16px | Default row/section spacing; wing leading/trailing pad baseline (`downloadWings`) |
| lg | 24px | Sheet section padding (duration picker groups) |
| xl | 32px | Camera-clearance-adjacent top padding contexts |
| 2xl | 48px | not used this phase |
| 3xl | 64px | not used this phase |

Exceptions: The collapsed-pill wing's camera-clearance **margin** value (the gap between wing content and the physical notch cutout) is **not** on this 4px grid anywhere in the codebase — `capsLockWings` uses `margin: 65`, `downloadWings` uses `margin: 20`, `updateWings` uses `margin: 30`, all arrived at through on-device measurement against the real notch, never guessed. **`timerWings(for:)` must start from `downloadWings`' or `capsLockWings`' existing margin/pad constants as its baseline and only retune on-device if content width differs — do not guess a fresh value from scratch** (per project convention: "reuse a proven wing's constants instead of guessing widths iteratively").

## Typography

Reuses the exact size/weight pairs already established across `NotchPillView.swift` — no new sizes introduced.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / secondary copy | 11px | regular (400) | 1.5 (e.g. "Start something in Spotify or Music." pattern) |
| Label / wing text | 12–13px | semibold (600) | 1.2 (e.g. "Caps Lock On", "Update" wing labels; countdown mm:ss uses 13px semibold + `.monospacedDigit()`) |
| Heading / sheet title, button captions | 16px | semibold (600) | 1.2 |
| Display / large glyphs | 28px | n/a (icon, not text) | n/a (e.g. `homeEmptyContent`'s 28px `music.note`, reused for the completion splash's checkmark glyph) |

**Exactly 2 weights declared: regular (400) for secondary/supporting copy, semibold (600) for everything else (labels, headings, primary numbers).** No bold/light/medium weights.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Black vertical alpha-gradient (existing shared shell material, VISUAL-01 — opaque near the notch, transparent toward the bottom edge) | Pill/wing/expanded-island background — unchanged, Timer does not touch shell material |
| Secondary (30%) | `Color.white.opacity(0.12)` fill on `RoundedRectangle(cornerRadius: 8)` | Duration/mode preset chips (D-02/D-03 picker), inactive `chipButton`-style rows |
| Accent (10%) | `Color.white` (full opacity) | Countdown digits, all icon glyphs, primary label text, and the **filled** `navCircleButton` state (white circle, black glyph) reserved for exactly one primary action per screen — mirrors the onboarding carousel's "Next/Finish is filled, Back is outlined" convention. In this phase: **Start** (in the duration sheet) and **Pause↔Resume** (the one state-toggling control in the expanded row) are the only filled circles; Reset, Add-Time, and Stop stay outlined per `navCircleButton(filled: false)`. |
| Second semantic (green) | `Color.green` (system green, existing app-wide convention) | Reserved **only** for the "session actively running" signal — the small live dot in the Pomodoro "Work · Cycle N" collapsed label (mirrors this codebase's existing use of green as the universal positive/active/success color: charging-connected ring, download-done checkmark, permission-granted ring). Not used for the Break segment, which stays plain white text (no urgency/negative color invented — out of scope, D-04..D-07 never asked for segment-specific coloring). |
| Destructive | none — not used | **Stop is deliberately NOT color-coded red.** This codebase has zero precedent for color-coded destructive actions anywhere in `NotchPillView.swift` (the shelf "Clear All" trash icon is plain `.white.opacity(0.7)`, fires immediately, no confirmation dialog). Stop (D-10) follows the identical convention: outlined white circle, distinguished from Pause/Reset/Add-Time by icon glyph only (`stop.fill` or `xmark`), fires immediately on tap, no confirmation sheet/alert. |

Accent reserved for: countdown digits, all button glyphs, filled-circle Start/Pause-Resume buttons, and the Pomodoro running-session live dot (green).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | **"Start Timer"** (D-01, locked exact wording) — button lives in the Home view, not Settings |
| Duration sheet mode toggle | Segmented control: **"Countdown" / "Pomodoro"** (D-03) |
| Countdown duration chips | **"5 min" / "10 min" / "20 min" / "30 min"** + **"Custom…"** opening a minute-count entry field (D-02) |
| Pomodoro duration chips | Same chip+custom pattern, applied per segment: **"Work"** row and **"Break"** row, each defaulting to **"25 min"** / **"5 min"** (D-04/D-05) |
| Collapsed pill — Countdown mode | Live `mm:ss` only, no label text |
| Collapsed pill — Pomodoro mode | **"Work · Cycle N"** / **"Break · Cycle N"** alongside the live `mm:ss` (D-07, locked exact wording, `N` = 1-based running cycle count) |
| Expanded controls | Four circular icon buttons, no text captions (icon-only, matches `navCircleButton`'s existing icon-only precedent) — Pause/Resume (filled, toggles glyph `pause.fill`↔`play.fill`), Reset (outlined, `arrow.counterclockwise`), Add Time (outlined, `plus`, +1 min per tap per D-09), Stop (outlined, `stop.fill`) |
| Completion splash — Countdown | Icon `checkmark.circle.fill` (28px) + **"Timer Done"**, standard ~3s auto-dismiss (this codebase's shared `scheduleActivityDismiss` default) plus the system notification sound (D-12) |
| Completion splash — Pomodoro segment transition | Same treatment as above, copy swaps per transition: **"Work Done"** (entering Break) / **"Break Done"** (entering Work) — fires at every transition per D-13, same ~3s duration and sound, not a shortened variant |
| Empty state | Not applicable — Timer has no dedicated empty view. The "Start Timer" button sits inline within whichever Home sub-state is already showing (Now Playing / Last Played / "Nothing Playing", Phase 30) and is always present regardless of music state |
| Error state | Custom-duration entry only: invalid/out-of-range minute count shows inline validation text **"Enter a number between 1 and 180."** directly under the entry field — no full-screen error state needed for this phase |
| Destructive confirmation | **None.** Stop and Reset both fire immediately on tap with no confirmation dialog — matches this app's existing "Clear shelf" precedent (immediate, icon-differentiated, never gated behind an alert) |
