## Plan 72.1-03: On-device UAT checkpoint — Summary

**Outcome:** Approved after 2 gap-closure rounds ("passt soweit erstmal").

This plan performed zero code changes itself — it is a human-verification checkpoint per its own `<verification>` contract. Three rounds of on-device testing occurred:

### Round 1 (initial checkpoint)
User rejected two of Plan 72.1-02's design choices on real hardware:
- **Opacity ramp (D-01/D-02/D-03):** bar dimming toward invisible at low fraction looked bad — user wanted the fill always at full opacity/brightness.
- **Digit-roll animation (D-04/D-04a/D-04b):** felt less smooth than the old `.numericText()` transition it replaced (though the old fade itself was NOT wanted back).

Closed by quick task `260731-61m`:
- Reverted the `OSDLevelBar` opacity ramp entirely — fill Capsule is now always fully opaque, independent of fraction. Removed all now-dead opacity-nudge plumbing (`osdOpacityMinNudge`/`osdOpacityMaxNudge` AppStorage keys, DEBUG menu items, tests) from `ActivitySettings.swift`/`NotchPillView.swift`/`AppDelegate.swift`/`ActivitySettingsTests.swift`. Kept Roll Speed ± and Reset/Print (trimmed to roll-speed-only).
- Retuned `DigitRollText`'s base `rollResponse` 0.15 → 0.30 for a smoother/slower glide, transition remained strictly `.move(edge:)`-based (D-04a preserved).
- Commit: `3729334`.

### Round 2 (re-verification)
The slower 0.30 response, combined with no debounce on rapid held-key repeats, caused digits to visibly stall — each new value change interrupted the prior digit's still-in-flight `.move` transition, so the digit appeared permanently "about to drop in" but never settled.

Fixed directly (user explicitly requested immediate implementation, no further quick-task ceremony):
- `DigitRollText` now decouples the rendered `displayValue` from the raw `value`: changes arriving within 120ms of the previous one snap instantly with no animation (imperceptible at that update rate); a change after a pause plays the spring roll. D-04a (move-only, never fade) preserved throughout.
- Commit: `6a24409`.

### Round 3 (final approval)
User confirmed: "Ja passt soweit erstmal" — approved.
