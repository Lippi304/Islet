## Zahlen-Stil (Ticker)

| Option | Description | Selected |
|--------|-------------|----------|
| Bestehende Animation reicht | Nur Timing/Spring-Feel ggf. leicht anpassen, kein neuer Ticker-Baustein | |
| Echtes Ziffern-Rollen bauen | Neuer Baustein: jede Ziffer einzeln als rollende Spalte, näher am shadcn-Referenzlook | |
| Zeig mir erst die App, dann entscheide ich | User wollte es live sehen | ✓ (initial) |

**Follow-up:** Claude built and launched the live Debug build so the user could trigger the OSD via volume/brightness keys.

**User's live reaction:** "Gefällt mir aktuell nicht da dieses Faden was es jetzt hat nicht immer die aktuelle Zahl anzeigt bzw nicht genug zeit da ist sie anzuzeigen deswegen brauche ich eine ohne fade wenn man schneller lauter oder leiser macht" — the existing fade transition doesn't stay readable during rapid key presses.

**Follow-up question:**

| Option | Description | Selected |
|--------|-------------|----------|
| Sofort springen, keine Animation | No transition at all — always exact current value | |
| Rollen/Rutschen ohne Fade (Odometer) | Digits stay fully opaque, slide like a mechanical counter — near shadcn number-ticker look | ✓ |

**User's choice:** Rollen/Rutschen ohne Fade (Odometer) → D-04, D-04a, D-04b
**Notes:** Rejects the existing `.contentTransition(.numericText())` approach entirely — this is net-new component work, not a tuning pass.
