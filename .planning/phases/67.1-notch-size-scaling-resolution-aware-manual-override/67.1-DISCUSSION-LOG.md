## Skalierungs-Scope

| Option | Description | Selected |
|--------|-------------|----------|
| Ein globaler Faktor für alles | One multiplier scales all view constants at once, keeps proportions consistent | ✓ |
| Nur bestimmte Views | Scale only select views, more control but inconsistent proportions | |

**User's choice:** Ein globaler Faktor für alles
**Notes:** Follow-up question — should the collapsed/idle pill also scale?

| Option | Description | Selected |
|--------|-------------|----------|
| Nur erweiterte Inhalte | Collapsed pill stays coupled to physical notch geometry (already resolution-adaptive); only expanded views scale | ✓ |
| Pille + erweiterte Inhalte | Collapsed pill also grows, risks mismatch with the physical notch cutout | |

**User's choice:** Nur erweiterte Inhalte

## Manuelle Kontrolle

| Option | Description | Selected |
|--------|-------------|----------|
| Ein Regler, freie % | Single proportional slider, simplest UI | |
| Feste Presets | 3-4 fixed size steps | |
| Getrennte Regler Breite/Tiefe | Two independent sliders, more flexible, risks non-proportional layouts | ✓ |

**User's choice:** Getrennte Regler Breite/Tiefe
**Notes:** Follow-up — what range should the two sliders cover?

| Option | Description | Selected |
|--------|-------------|----------|
| 80%–150% | Covers both "too small at high resolution" and slight shrink | ✓ |
| 100%–200% (nur vergrößern) | Enlarge-only range | |
| Anderer Bereich | User-specified custom range | |

**User's choice:** 80%–150%

## Automatischer Auslöser

| Option | Description | Selected |
|--------|-------------|----------|
| Nur manuell, kein Auto | No detection mechanism, sliders are the only lever | |
| Auto anhand gewählter Bildschirmauflösung | App reads current scaled resolution and sets a sensible default | ✓ |

**User's choice:** Auto anhand gewählter Bildschirmauflösung
**Notes:** Follow-up — what should the "100%" reference baseline be?

| Option | Description | Selected |
|--------|-------------|----------|
| Deine bisherige/Standard-Auflösung | The resolution the current fixed pt values were designed for | |
| Physische Bildschirmgröße/Zoll | Physical display diagonal instead of resolution | |
| Ich sage dir die genaue Referenz | User provides the exact reference | ✓ |

**User's choice:** Ich sage dir die genaue Referenz — "Ich habe geguckt angepasst ist die Notch auf 1470x956 und aktuell nehme ich 1710x1112 da ist die eben zu klein aber so hast du schonmal eine referenz"
**Notes:** Baseline locked at 1470×956 points; current problem resolution 1710×1112. Ratio verified uniform across width/height (~1.163×) — see CONTEXT.md `<specifics>`.

## Zusammenspiel Auto + Manuell

| Option | Description | Selected |
|--------|-------------|----------|
| Auto setzt Default, manuell justiert oben drauf | Sliders start at the auto-computed default and can be moved from there; resolution change resets to new auto default | ✓ |
| Auto nur beim allerersten Start | One-time calibration only, later resolution changes don't touch the sliders again | |

**User's choice:** Auto setzt Default, manuell justiert oben drauf
**Notes:** Follow-up — should the manual value be remembered per-resolution?

| Option | Description | Selected |
|--------|-------------|----------|
| Ein globaler manueller Wert | Single manual offset applies regardless of which resolution is active | ✓ |
| Pro Auflösung gemerkt | Each detected resolution keeps its own remembered slider value | |

**User's choice:** Ein globaler manueller Wert
