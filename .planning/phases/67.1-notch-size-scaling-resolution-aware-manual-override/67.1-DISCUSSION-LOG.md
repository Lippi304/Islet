## Amendment 2026-07-26: Collapsed Pill Live Re-Measurement Bug

**Trigger:** On-device UAT during Plan 05 found the collapsed pill mismatched to the real camera notch at the 1710×1112 resolution — user reopened D-02 via `/gsd-discuss-phase 67.1`.

| Option | Description | Selected |
|--------|-------------|----------|
| Pill is genuinely misaligned to the camera | Points to a live-measurement bug, not a proportion issue | ✓ |
| Pill matches camera fine, just looks small next to bigger content | Would be a visual-proportion issue, not a bug | |
| Not sure — check on-device first | Defer to a diagnostic pass before deciding | |

**User's choice:** Pill is genuinely misaligned to the camera

| Option | Description | Selected |
|--------|-------------|----------|
| Wrong immediately after switching resolution live | Points to stale re-measurement, not re-computing on the live change | ✓ |
| Only wrong after a full app relaunch | Would point to a wrong formula, not staleness | |
| Not sure / haven't tested both ways | Unconfirmed | |

**User's choice:** Wrong immediately after switching resolution live

**Symptom (free text):** "Ne die position bleibt fix aber dadurch das ja jetzt mehr pixel sind wird es ja kleiner und die normale Kamera auf dem Display bleibt ja und dadurch ist dann die kamera so das sie bisschen was von innen abschneidet und die tiefe ist kleiner und nicht mehr passend zur kamera dadurch halt das eben bei höherer auflösung ja das es ja mehr pixel werden" — position unaffected, depth/height shrinks and no longer matches the camera right after a live resolution switch.

| Option | Description | Selected |
|--------|-------------|----------|
| Yes — fix live re-measurement, keep pill pixel-perfect to hardware | D-02 reaffirmed (no D-01 scale factor on the collapsed pill); amended with a correctness-fix requirement (D-09/D-10) | ✓ |
| No — actually want the collapsed pill visually bigger at higher resolutions | Would apply D-01's scale factor to the collapsed pill too, deliberately larger than the real notch | |

**User's choice:** Yes — fix live re-measurement, keep pill pixel-perfect to hardware
**Notes:** Confirmed this is a bug-fix, not a scope reversal of D-02. See CONTEXT.md D-09/D-10 for the locked decisions and `<specifics>` for the full repro detail.
