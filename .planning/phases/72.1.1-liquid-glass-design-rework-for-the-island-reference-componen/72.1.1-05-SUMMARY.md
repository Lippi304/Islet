# Phase 72.1.1 Plan 05: Tier 2 Content Surfaces — Calendar, Weather, Tray Summary

**Calendar event cards, the Weather widget, and Tray file tiles now render real macOS 26+ Liquid Glass via a guarded `.glassEffect(.regular.tint(Color.white.opacity(0.06)))`, reusing EventRow's pre-existing card-background convention verbatim across all three (two of which previously had no background at all), with an unchanged legacy plain-fill fallback below macOS 26.**

## Performance

- **Duration:** ~20 min
- **Completed:** 2026-07-31T21:25:05Z
- **Tasks:** 3 (2 auto, 1 checkpoint:human-verify)
- **Files modified:** 2

## Accomplishments

- `EventRow`'s existing `.background(RoundedRectangle(...).fill(Color.white.opacity(0.06)))` is now `.background { if #available(macOS 26.0, *) { ... .fill(Color.clear).glassEffect(.regular.tint(Color.white.opacity(0.06)), in: ...) } else { ... .fill(Color.white.opacity(0.06)) } }` — the separate hover-stroke `.overlay(...)` was left untouched.
- `weatherFullContent` gained a new `.padding(12)` + the same guarded glass card background, placed before its existing `.frame(maxWidth: .infinity)` — the 44pt weather icon and 32pt temperature readout font sizes were left unchanged.
- `ShelfItemView` gained a new `.padding(6)` + the same guarded glass tile background around its icon+caption `VStack`, placed before `.contentShape(Rectangle())`, `.onTapGesture`, `.onDrag`, and the top-trailing delete-badge `.overlay` — so tap/drag hit-testing and the badge's `.offset(x: -2, y: 2)` stayed anchored to the same VStack edges as before. The 40x40pt icon frame and `maxWidth: 56` caption frame (Phase 32/TRAY-05 locked values) were left unchanged.
- On-device UAT confirmed all 3 checks: Calendar event title/time/color-dot legible with the hover-stroke still visible, Weather card reads as a natural (not jarring) box with a crisp icon/temperature readout, Tray tiles show the glass background with a legible caption and a delete badge that stays visually distinct on top.
