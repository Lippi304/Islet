## Files Created/Modified

- `Islet/ActivitySettings.swift` - Added 5 `static let debugGlass*NudgeKey` constants under the `debug.glassTuner.*` namespace, inside the existing `#if DEBUG` block, after `debugOSDRollSpeedNudgeKey`.
- `Islet/Notch/NotchPillView.swift` - Added 5 `@AppStorage(ActivitySettings.debugGlass*NudgeKey)` read points (inside `#if DEBUG`) and 5 always-compiled `private var glass*Nudge: CGFloat` computed properties (Release branch returns 0), mirroring `wingLeadingNudge`'s exact shape.
- `Islet/AppDelegate.swift` - Added the `glassTunerMenu` `NSMenu` (10 nudge items + separator + Reset/Print) between the existing OSD Tuner submenu and the "Preview Wing" section; added 10 `@objc` minus/plus actions each calling `adjustWingNudge(ActivitySettings.debugGlass...NudgeKey, by:)`; added `debugGlassTunerReset()` (zeroes all 5 keys) and `debugGlassTunerPrint()` (prints all 5 values plus a bake-target hint naming `liquidGlassEffectLayer` and `LiquidGlassParameters.collapsed`/`.expanded` in `LiquidGlassShader.swift`).

## Decisions Made

- Reused `adjustWingNudge(_:by:)` directly for all 10 new actions rather than writing a second, differently-named helper — the plan's interfaces section explicitly called this out ("generic helper (name notwithstanding)").
- Named the new nudge properties/keys under a distinct `debug.glassTuner.*` namespace (not `debug.wingTuner.*`), since this is conceptually a separate tuner group from the Wing/OSD Tuner, per the plan's explicit instruction.
