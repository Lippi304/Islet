## Pattern Assignments

### `Islet/Notch/NotchPillView.swift` — `liquidGlassEffectLayer` (D-01 full coverage, D-04 transition fix)

**Analog:** same function's current code + its own documented pre-D-20a prior state (`35-CONTEXT.md` D-20/D-20a).

**Current code to revert/extend** (`NotchPillView.swift:747-773`):
```swift
@ViewBuilder
private func liquidGlassEffectLayer(shape: NotchShape, size: CGSize, parameters: LiquidGlassParameters) -> some View {
    if materialStyle == .liquidGlass {
        if #available(macOS 26.0, *) {
            let rimWidth = liquidGlassRimBandWidth(shape: shape, size: size, parameters: parameters)
            Color.clear
                .frame(width: size.width, height: size.height)
                .glassEffect(.regular.tint(Color.black.opacity(0.35)), in: LiquidGlassRimRingShape(base: shape, bandWidth: rimWidth))
                .allowsHitTesting(false)
        } else {
            legacyLiquidGlassEffectLayer(shape: shape, size: size, parameters: parameters)
        }
    } else {
        EmptyView()
    }
}
```

**D-01 target shape** — swap the `in:` argument from `LiquidGlassRimRingShape(...)` back to the bare `shape` (RESEARCH.md Pattern 1, confirmed to have compiled/rendered pre-D-20a):
```swift
.glassEffect(.regular.tint(Color.black.opacity(0.7)), in: shape)   // full `shape`, not LiquidGlassRimRingShape
```
Tint alpha `0.7` is the D-20-era starting literal (UI-SPEC "Glass tint starting point") — route through the DEBUG tuner, do not hardcode a different value without on-device confirmation.

**D-04 scoped `GlassEffectContainer`** — wrap ONLY this function's `.glassEffect(...)` call, never the outer `presentationSwitch`. No working precedent exists in this codebase (the one prior attempt, whole-hierarchy-scoped, was reverted — see "No Analog Found" below); RESEARCH.md Pattern 2 is the only available reference shape:
```swift
@Namespace private var glassNS   // separate from `ns` (matchedGeometryEffect), avoids cross-interference

GlassEffectContainer {
    Color.clear
        .frame(width: size.width, height: size.height)
        .glassEffect(.regular.tint(Color.black.opacity(0.7)), in: shape)
        .glassEffectID("islandGlass", in: glassNS)   // SAME id/namespace at all 4 shell call sites
        .allowsHitTesting(false)
}
```

**Structural constraint (from `matchedGeometryEffect` continuity precedent, WR-02):** this logic stays inside the EXISTING `liquidGlassEffectLayer` function, applied via the existing `.overlay(liquidGlassEffectLayer(...))` call at all 4 shell sites — never a new sibling/wrapper view.
