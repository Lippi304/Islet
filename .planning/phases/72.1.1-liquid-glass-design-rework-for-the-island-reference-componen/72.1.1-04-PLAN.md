<objective>
Extend Liquid Glass to the two D-06 "Tier 1" control elements — Quick Action buttons (`quickActionButton`) and view-switcher tabs (`navCircleButton`) — per CONTEXT.md D-06 and UI-SPEC's Tier 1 contract (safe for fuller glass intensity, since these are navigation-layer chrome, not content).

Both elements already have a background fill that encodes state (hover/disabled for buttons, selected/unselected for tabs) — this plan swaps the plain `Color.fill(...)` for `.glassEffect(.regular.tint(...))` using the SAME opacity value the existing fill already used, so the state signal is preserved exactly (just rendered as real glass instead of a flat color) rather than adding a second, separate glass layer alongside it.

Purpose: Apply the phase's glass rework to the two lowest-legibility-risk D-06 elements first (controls, not content — RESEARCH.md Pitfall 3's own risk-tier ordering).
Output: Quick Action buttons and switcher tabs render with Liquid Glass backgrounds; on-device UAT confirms hover/disabled/selected states stay unambiguous.
</objective>
