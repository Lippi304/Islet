- **After every task commit:** `xcodebuild build -scheme Islet -configuration Debug` plus the structural grep check below where applicable — visual/material correctness cannot be sampled automatically.
- **After every plan wave:** Full XCTest suite (`xcodebuild test -scheme Islet -destination 'platform=macOS'`) plus a fresh on-device visual pass.
- **Before `/gsd-verify-work`:** Full suite must be green AND on-device UAT checkpoint(s) must be approved.
- **Max feedback latency:** ~120 seconds (build+test); on-device visual passes have no automatable latency bound.
