## Dynamischer Hintergrund / Reaktivität (Dynamic Background / Reactivity)

| Option | Description | Selected |
|--------|-------------|----------|

| Leichte Reaktivität (z.B. beim Expandieren/Hover) | Reacts to existing states only | |

**User's choice:** Free text (first pass) — "Na überall genau da wo die Island ist sol der glass look sein dazu gehört ja auch die Expand Animation und auch die kleine Expanded version und so." Interpreted as answering a coverage-across-states question rather than reactivity; asked a direct follow-up.

Follow-up: "Nur durchgehende Sichtbarkeit in allen Zuständen, oder zusätzlich Live-Reaktivität auf Maus/Bewegung?"

| Option | Description | Selected |
|--------|-------------|----------|
| Nur durchgehende Sichtbarkeit | Glass present in every state (pill, mid-animation, both expanded sizes), no new interaction mechanic | ✓ |
| Sichtbarkeit + Live-Reaktivität | Additionally reacts live to mouse/motion like real Dock | |

**User's choice:** Nur durchgehende Sichtbarkeit
**Notes:** This directly implicates the known black-flash-during-transition bug (glass must be visible mid-animation, not just at rest) — confirmed explicitly in the Transition-Bug area below.
